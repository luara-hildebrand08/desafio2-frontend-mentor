# Frontend Mentor -  Solução para componente de cartão de pré-visualização de produto 

## Descrição
Este projeto apresenta um cartão de pré-visualização de produto, onde os usuários podem visualizar o layout adaptado de acordo com o tamanho da tela do dispositivo. A interface também possui um botão interativo.
